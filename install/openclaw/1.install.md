# Debian install
创建一个新用户. 然后用install-cli。
```
adduser xuser
usermod -aG sudo xuser
su - xcuser
curl -fsSL --proto '=https' --tlsv1.2 https://openclaw.ai/install-cli.sh | bash
echo 'export PATH="$HOME/.openclaw/bin:$PATH"' >> ~/.profile
export PATH="$HOME/.openclaw/bin:$PATH"
openclaw --version

usermod -aG sudo ocuser
exit
su -l ocuser
```

在debian，光看到 groups 里有 sudo 还不够；还要看 /etc/sudoers 里是否真的有类似这条规则：%sudo ALL=(ALL:ALL) ALL
先用 root 执行这一条，检查 sudoers 里有没有放行 sudo 组：
`grep -E '^[[:space:]]*%sudo[[:space:]]+ALL=\(ALL(:ALL)?\)[[:space:]]+ALL' /etc/sudoers /etc/sudoers.d/* 2>/dev/null`
如果这条命令没有输出任何东西，基本就是这个原因。
最直接的修法，用 root 执行：
`printf '%%sudo ALL=(ALL:ALL) ALL\n' > /etc/sudoers.d/90-sudo-group && chmod 440 /etc/sudoers.d/90-sudo-group`
然后检查语法:
```
visudo -c
exit
su -l ocuser
```

另一个解决方案.
回到root.创建
```
cat >/etc/systemd/system/openclaw-gateway.service <<'EOF'
[Unit]
Description=OpenClaw Gateway
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ocuser
Group=ocuser
WorkingDirectory=/home/ocuser
Environment=HOME=/home/ocuser
Environment=PATH=/home/ocuser/.openclaw/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
ExecStart=/home/ocuser/.openclaw/bin/openclaw gateway --port 18789
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF
```

4. 让服务立刻启动，并且以后开机自动启动
```
systemctl daemon-reload
systemctl enable --now openclaw-gateway.service
```

5. 用 systemd 自己检查，而不是用 openclaw status
先看服务状态：
`systemctl status openclaw-gateway.service --no-pager`
再看实时日志：
`journalctl -u openclaw-gateway.service -f`


7. 以后怎么管它:全部用 root：
```
systemctl restart openclaw-gateway.service
systemctl stop openclaw-gateway.service
systemctl start openclaw-gateway.service
systemctl status openclaw-gateway.service --no-pager
journalctl -u openclaw-gateway.service -n 100 --no-pager
```
